# 04. 3D映像の作り方と品質

## 1. 方針

- 中継映像らしさを優先：スタンド前の高い位置からの望遠、局面ごとのカメラの切り替え、被写体の広がりに合わせた画角。
- 外部の3Dモデル・写真・映像は使わず、すべて手続き的に生成（権利処理が不要で、読み込みも軽い）。

## 2. 構成要素

| 要素 | ファイル | 内容 |
|---|---|---|
| 水面 | `environment.ts`, `textures.ts` | さざ波の法線2枚を違う向き・速さで流す。IBL の映り込み（強さは河川らしく控えめ）。波高・天候で凹凸と色を変える |
| 艇と選手 | `boatModel.ts` | 押し出し＋面取りの艇体、番号板、モーター、膝をついた前傾姿勢の選手。速度・加速で艇首、横加速度で傾き、波で揺れ |
| しぶき・泡 | `effects.ts` | しぶきは重力つきの粒子（ターンでは外へ）、泡は広がりながら薄れる板。走った線が水面に残る |
| 施設 | `environment.ts` | 護岸・2層スタンドと観客・横ピット・ターンマーク・コース外側のブイ・スタートラインの標識・大時計・大型映像装置・吹き流し・対岸の堤防と街並み・橋 |
| カメラ | `camera.ts` | スタート／1マーク／先頭追走／2マーク／注目艇／ゴール／全景。自動は先頭の位置で切り替え（2.5秒以内の再切り替えはしない） |
| ポストプロセス | `post.ts` | 高画質のみ：艇を除いたモーションブラー（流し撮り）と被写界深度 |

## 3. 確認方法

開発サーバーで、締切→結果へスキップ→シークで、スタート前・スタート・1マーク・バックストレッチ・2マーク・最終周回・ゴールの各場面を
中画質（1280×720）とスマートフォンの低画質（390×844）で撮影して確認した。2D 上空図は WebGL を無効にしたブラウザで、購入から確定までを確認した。

調整した点：カメラが建物の中に入らないようスタンド前（護岸から3m）に置く／ゴールのカメラは岸の標識より高くする／
水面のきらめきが強すぎたため法線と映り込みを弱める／泡が太陽の色で黄ばまないよう白寄りにする。

## 4. 素材と権利

- テクスチャ（水面・泡・芝・座席・窓・雲・大時計の文字盤・番号）はすべて Canvas で生成。
- フォントはシステムフォント。three.js は MIT ライセンス。
- 実在のレース場の写真・図面・ロゴ・映像・公式キャラクターは使っていない（[05](./05-venue-reference.md)）。

## 5. 今後の課題

- 水面の実際の起伏（頂点の変位）と、艇の引き波が他の艇を揺らす表現。
- 選手の体の動き（ターンでの体重移動）。
- スタンドの映り込み（スクリーンスペース反射）。
