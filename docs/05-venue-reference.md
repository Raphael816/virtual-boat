# 05. 水面の形の出典と推定箇所（江戸川を参考にした非公式の再現）

このアプリのレース場「翠川ボートレース場」は **架空** です。水面の形と特徴の一部は、江戸川の公開情報を参考にしています。
実在のレース場・施行者・団体とは関係がなく、承認や監修も受けていません。

## 1. 参照した資料と使い方

| 資料 | 参照した内容 | 使い方 |
|---|---|---|
| ボートレース公式サイトのレース場紹介（江戸川） | 河川を利用した水面であること、潮の干満（上げ潮・下げ潮）と風で水面が荒れやすいこと、進入は枠なりが多いこと | 文章の事実だけを参考にし、文章・画像・図はコピーしていない |
| 一般のファン向け解説サイト（複数） | 1マーク付近の幅が約37mと狭いこと、1マークがスタンド寄りにあること、横ピットであること、1コースの1着率が全国平均より低いこと、上げ潮はスロー勢・下げ潮はダッシュ勢に向くと言われること | 傾向の目安として数値を参考にした。公式の数値ではないため断定しない |
| ボートレースの一般的なルール | 1周600m×3周、フライングスタート（0〜1秒）、フライング・出遅れは返還欠場、券種、控除率25% | ルールとして実装 |

## 2. 公開情報に合わせた箇所

- 1周600m・3周（1,800m）、左回り、ターンマーク2つ。
- 1マーク付近の水面の幅 約37m（他の区間は45mとした）。
- 1マークはスタンド側の直線の先（スタンドに近い）。
- 水面条件：潮（上げ潮・下げ潮・潮止まり）・風・波高を毎レース変える。上げ潮はスロー勢、下げ潮はダッシュ勢にわずかに有利（ST に ±0.01秒）。
- 1コースの1着率を全国平均より低い約46〜48%に調整（シミュレーションの係数で合わせた目安であり、実データの再現ではない）。

## 3. 推定で補った箇所（実際と異なる可能性があります）

| 項目 | このアプリでの値・表現 | 備考 |
|---|---|---|
| スタートラインから1マークまで | 150m | 一般的な水面の目安からの推定 |
| ターンの内側の線の半径 | マークから15m | モデル化のための値 |
| スタンドの規模・形 | 2層スタンド・ガラス張りの建物（幅約230m） | 一般的な構成から作ったオリジナル。実物の外観ではない |
| 大時計の位置 | 1マークの先の水上 | 推定 |
| 横ピットの位置・規模 | スタンド側の岸、2マーク寄り、長さ70m | 推定 |
| 対岸 | 堤防・河川敷の木立・住宅と中層の建物 | 一般的な河川の風景。実在の建物ではない |
| 橋・大型映像装置 | 下流に桁橋、スタンド横に映像装置 | 風景としての架空の配置 |
| 潮の流れの向きと強さ | 上げ潮は上流へ、下げ潮は下流へ（直線の速度に ±0.3m/s） | 推定 |
| 1マークのインが流れやすい度合い | 流れの量 ×1.6 | 1コースの1着率を合わせるための推定 |

## 4. 名称・ロゴ・素材の扱い

- 実在のレース場名・施行者名・公式ロゴ・キャラクター・建物の写真・公式映像・実況音声は使っていません。
- 選手はすべて架空です。所属支部は都道府県名を一般名称として使っています。
- 艇番の色（1白・2黒・3赤・4青・5黄・6緑）、券種名、決まり手の名称は、競技で一般に使われる呼び方として使っています。
- 実在の名称や公式素材を使う場合は、事前に権利者の許可とライセンスを確認します。

## 5. シミュレーションへの反映

- `core/course.ts`：1周の形・1マーク付近の幅・スタート前の助走の直線。
- `core/sim.ts`：スロー／ダッシュ、1マークの進入と流れ、潮・風・波の影響（係数は `TUNE`）。
- `tests/course.test.ts`・`tests/sim.test.ts`：寸法と、1コースの1着率・決まり手の分布を検査。
