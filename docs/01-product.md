# 01. プロダクト企画

## 1. サービス概要と想定ユーザー

**Virtual Boat（仮称）** は、架空の選手・架空のレース場（翠川ボートレース場）で行うボートレースのシミュレーションです。
水面の形は江戸川の公開情報を参考にした非公式の再現です（[05](./05-venue-reference.md)）。
レース前に選手の級別・勝率・平均ST、モーター、展示タイム、潮・風・波、オッズを検討して **仮想コイン（デモコイン）** で投票し、
レース中は3Dの中継風映像で展開を見守り、レース後に着順・決まり手・勝因・収支を振り返れます。

- 結果は「スタート × 1マークの攻防 × ターン × モーター × 水面 × 乱数」で決まり、レース後に理由が解説されます。
- デモコインは **購入も換金もできず、金銭的な価値はありません**。

### 想定ユーザー

| セグメント | ニーズ | 提供価値 |
|---|---|---|
| ボートレースファン | 予想する楽しさ、展開（逃げ・差し・まくり）を読む面白さ | コース別の傾向・決まり手が現実に近い、納得感のあるシミュレーション |
| 未経験のゲーム好き | 3Dの迫力、手軽さ | 遊び方の案内、単勝・複勝から始められる導線 |
| データ・戦略好き | 能力値と結果の関係を分析したい | ST・1マークの進入・ターンの流れ・引き波の内訳、seed 検証の公開 |
| 将来の事業パートナー／法務 | 公正性・安全性の確認 | 監査ログ、コミット・リビール方式、責任ある利用の機能 |

対象年齢：試作でも **18歳以上の自己申告** を前提とします。

## 2. MVPの範囲

### MVPに含める機能

- **レース**：1開催12レース・各6艇・1,800m（600m×3周）。天候・風・波・潮（上げ潮／下げ潮／潮止まり）・時間帯（デイ／薄暮）が変わる
- **出走表**：級別・支部・年齢・体重・勝率・2連対率・平均ST・モーター（番号・2連対率）・ボート・展示タイム
- **シミュレーション**：フライングスタート（ST・フライング／出遅れ）、スロー／ダッシュ、1マークの進入（逃げ・差し・まくり・まくり差し）、ターンの流れ、引き波、モーター性能、潮・風・波
- **券種**：3連単・3連複・2連単・2連複・拡連複・単勝・複勝（控除率25%）。フライング・出遅れの艇を含む券、不成立の券種は返還
- **公正性**：コミット・リビール、ハッシュチェーンの監査ログ、seed による再計算
- **観戦**：3D映像（自動・全景・スタート・1マーク・先頭追走・2マーク・注目艇・ゴール）、大時計、引き波・しぶき、実況、周回表示、リプレイ（速度変更・シーク）
- **代替表示**：2D上空図（WebGL が使えない場合や利用者が選んだ場合）
- **収支**：購入履歴（返還を含む）、レース別収支、残高推移
- **責任ある利用**：年齢確認、利用時間のリマインダー。投票上限・休止・自己排除はコードを残し、デモ設定でオフ（フラグで再び有効にできる）
- データは端末内（localStorage）に保存し、サーバーは使いません

### 後回しにする機能

| 機能 | 理由 |
|---|---|
| 実際のお金での入金・出金・賭け | 法務確認と許認可が前提（[03](./03-legal-and-safety.md)） |
| デモコインの購入 | 資金決済法・景品表示法・ストア規約の検討が必要 |
| 進入の乱れ（前付け）・フォーメーション／ボックス買い | 枠なり進入と1点買いで体験を検証してから |
| 節間（予選→準優→優勝戦）・選手の成績の蓄積 | コアの体験が検証できてから |
| 音声実況・BGM | 権利処理と制作が必要 |

## 3. 画面一覧と主要フロー

| # | 画面 | パス | 主な要素 |
|---|---|---|---|
| S1 | トップ | `#/` | 次のレース、残高と本日の収支、遊び方への導線 |
| S2 | 遊び方・仕組み | `#/guide` | 券種、オッズと払戻、返還のルール、結果の決まり方、公正性 |
| S3 | レース一覧 | `#/races` | 12レースの状態と水面条件 |
| S4 | レース詳細・観戦 | `#/race/:id` | 3D／2D映像、出走表、オッズ、投票、実況、結果と振り返り |
| S5 | 選手の詳細 | `#/racer/:id` | 能力のレーダーチャート、勝率・平均ST、この開催のモーターと出走 |
| S6 | 購入内容の確認 | S4内のダイアログ | 券種・選んだ艇・賭け金・現在のオッズ・想定払戻・購入後の残高 |
| S7 | 収支 | `#/history` | 残高推移、レース別収支、購入履歴 |
| S8 | 設定 | `#/account` | 画質、2D表示、監査ログの検証、データの初期化 |

```
初回訪問 → 年齢確認・デモの説明 → トップ（10,000コイン付与）
   → レース一覧 → レース詳細（出走表・選手の詳細で検討）
   → 券種と艇を選び金額を入力 → 確認ダイアログ → 購入
   → 締切（オッズ確定）→ 待機行動・大時計 → スタート → 3周の観戦
   → 確定（着順・決まり手・払戻・返還・振り返り・seed の公開と検証）→ 収支
```

### レイアウト方針（スマートフォン優先）

- スマートフォン：映像（16:9）を上部に、その下をタブ（出走表／投票／オッズ／実況／結果）で切り替える。
- PC（1024px以上）：左に映像とタブ、右に投票パネル。
- 落ち着いた濃紺のスポーツ中継のトーン。カジノ風の演出や煽る表現は使わず、結果は「的中／不的中／返還」と事実だけを表示します。
