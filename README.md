# Virtual Boat（仮称）

架空の選手で遊ぶ **ボートレースのシミュレーション**（デモ）です。賭けには **デモコイン** だけを使います。
デモコインは購入・換金・譲渡ができず、金銭的な価値はありません。

- レース場「翠川ボートレース場」と選手はすべて架空です。
- 水面の形は **江戸川の公開情報を参考にした非公式の再現** です（1周600m×3周、1マーク付近の幅約37m、スタンド寄りの1マーク、潮・風・波）。
  出典と推定箇所は [docs/05-venue-reference.md](docs/05-venue-reference.md) に記載しています。実在のレース場・団体とは関係ありません。
- 実際のお金を扱う機能はありません。検討する前に確認すべき事項は [docs/03](docs/03-legal-and-safety.md) にまとめています。

## できること

- 1開催12レース・各6艇の出走表（級別・勝率・平均ST・モーター・展示タイム・潮・風・波）
- 7券種（3連単・3連複・2連単・2連複・拡連複・単勝・複勝）。パリミュチュエル方式のオッズ（控除率25%）
- フライング・出遅れの返還欠場、完走艇不足による不成立の返還
- 3D観戦（待機行動・大時計・スタート・1マーク・2マーク・ゴールのカメラ、引き波としぶき）と 2D 上空図
- 実況、決まり手（逃げ・差し・まくり・まくり差し・抜き・恵まれ）、レース後の振り返り
- コミット・リビールと seed による結果の再計算、ハッシュチェーンの監査ログ
- 収支（返還を含む）、年齢確認、利用時間のリマインダー

## 開発

```sh
npm install
npm run dev        # 開発サーバー
npm test           # テスト（Vitest）
npm run build      # 型チェック＋本番ビルド（dist/）
```

### GitHub Pages での公開

`.github/workflows/pages.yml` はリポジトリ変数 `ENABLE_PAGES=true` のときだけ動きます。
Settings → Pages で Source を「GitHub Actions」にしてから変数を設定してください。

## ディレクトリ構成

```
src/
  core/      シミュレーション（sim）・水面（course）・開催（meeting）・券種・オッズ（pool）・確率推定・進行・台帳・監査ログ
  data/      架空の選手と艇番の色
  render/    再生（playback）・2D 上空図・3D（three/：水面と施設・艇・しぶきと泡・カメラ・ポストプロセス）
  ui/        画面（トップ・レース一覧・レース詳細・選手・収支・遊び方・設定）
tests/       Vitest
docs/        企画・設計・法務チェックリスト・映像・出典
```
